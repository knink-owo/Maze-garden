## 1. 第一次：打开你的 vault

1. 打开 Obsidian → **打开文件夹作为库（Open folder as vault）**；
2. 选择 `D:\Projects\Maze-garden\content`；
3. 你会看到 `index.md`（入口文章）和 `思想/`、`技术/`、`关于/` 文件夹——这就是你的博客。

> 想预览网站：在项目根目录 `D:\Projects\Maze-garden` 运行
> ```bash
> npm i          # 第一次
> npx quartz build --serve
> ```
> 打开 http://localhost:8080。

## 2. 每篇笔记的写法

新建笔记（任意文件夹，可自己新建，如 `生活/`），开头写：

```markdown
---
title: 文章标题
description: 一句话摘要（显示在反向链接和悬停预览里）
---

正文……用 [[其他文章]] 链接房间，用 ![[图片.png]] 插图。
```

- `title` 可不写（默认用文件名）；
- `description` **建议必写**——反向链接和预览都靠它；
- 想分享时加 `permalink: pretty-url`（干净 URL，改名不变）。

## 3. Obsidian Git 插件（自动发布）

1. Obsidian 设置 → **第三方插件（Community plugins）** → 关闭安全模式；
2. 浏览 → 搜索 **Git**（作者 Vinzent，即 Obsidian Git）→ 安装并启用；
3. 设置 Obsidian Git：

| 设置项 | 建议值 | 说明 |
| --- | --- | --- |
| Auto backup after stopping edit | `1 minute` | 停止编辑 1 分钟后自动提交推送 |
| Auto backup interval | `10 minutes` | 兜底：每 10 分钟检查一次 |
| Commit message | `auto: {{date}}` | 自动提交信息 |
| Push on backup | ✅ 开启 | 提交后自动 push |

> ⚠️ 前提：该文件夹是一个 git 仓库（本项目已初始化，分支 `v5`），
> Obsidian Git 会自动在仓库里执行 `git add/commit/push`。
> 第一次用前确认 Obsidian Git 的 **Vault source** 指向 `content/`（git 根目录自动识别为仓库根）。

4. 之后你只需要：**写字 → 等 1 分钟**，网站自动更新（GitHub Actions 约 1-2 分钟完成构建发布）。

## 4. 首次部署（已完成，供复现）

```bash
# 1. 创建 GitHub 仓库并推送（已做：knink-owo/Maze-garden，分支 v5）
gh repo create knink-owo/Maze-garden --public --source=. --remote=origin --push

# 2. 开启 GitHub Pages（来源：GitHub Actions）——已通过 API 设置
gh api --method POST repos/knink-owo/Maze-garden/pages -f build_type=workflow

# 3. 以后每次只需：
npx quartz sync        # 提交并推送（等价于手动 git add/commit/push）
```

部署流水线：`.github/workflows/deploy.yml`（push 到 `v5` 分支 → `npm ci` → 构建 → deploy-pages）。

## 6. 常见问题

**Q：网站没更新？**
A：先看 Actions：`gh run list` / GitHub 仓库 Actions 页。常见原因：提交到了别的分支（必须是 `v5`）；Obsidian Git 没 push 成功（看它的日志）。

**Q：日期显示不对？**
A：日期来自 git 历史。如果补录旧文，在 frontmatter 写 `date: 2024-05-01` 覆盖；改过的文章重新 commit 后"修改时间"才会更新。

**Q：音乐图标不出现？**
A：把音频文件放到 `quartz/static/music/`（mp3/ogg/wav/m4a），重新构建（push 后自动）。

**Q：想改站点名/颜色？**
A：编辑 `quartz.config.yaml` 的 `pageTitle` / `theme.colors`，push 即可。

**Q：URL 太长/是编码的？**
A：默认中文文件名会百分号编码。想分享某篇时，在 frontmatter 加 `permalink: pretty-url`。

**Q：加不了本地插件？**
A：Windows 无开发者模式下符号链接不可用（EPERM）。本项目自定义组件已放在 `quartz/components/maze/`（核心目录），无需安装。
