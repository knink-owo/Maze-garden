---

## 1. 项目定位

一个极简主义的个人知识博客（数字花园）。核心理念：

- **没有导航栏、没有分类目录、没有标签云、没有时间线归档**；
- 访客进入主页，只有一篇**核心入口文章**；
- 文章之间只通过 **Obsidian 双链 `[[...]]`** 连接——像迷宫的房间与门；
- 每篇文章底部自动生成**反向链接**（标题 + 摘要），显示"哪些房间通向这里"；
- **关系图谱**默认隐藏，访客可主动召唤（右上角按钮）；
- 右上角一组低调工具：🔍 搜索 · ♪ 音乐 · 🎲 随机漫步 · 🕘 最近更新 · 🕸 图谱 · ☀/🌙 主题切换；
- 屏幕左缘"目录"滑块：点击展开左侧抽屉（当前文章目录 + 字数）。

## 2. 技术选型与理由

| 方案 | 结论 |
| --- | --- |
| Obsidian + **Quartz 5** | ✅ **采用**（TypeScript/Node，静态生成） |
| Jekyll + digital-garden-jekyll-template | ❌ Ruby 工具链维护弱，模板偏"博客感" |
| Next.js + 自研双链解析器 | ❌ 等于重写一个 Quartz，维护成本高 |

**选 Quartz 5 的理由（均有官方文档佐证）：**

1. **需求几乎零距离**：`[[双链]]` 原生解析（别名/小节/嵌入/图片）；反向链接自动生成；关系图谱默认折叠、可召唤；**悬停预览（Popover）可滚动阅读全文**，`[[文章#标题]]` 自动定位到该小节——正是"迷宫"体验所需的全部交互；
2. **Obsidian 即内容源**：`content/` 目录直接作为 vault 打开，零迁移；
3. **GitHub Pages 官方支持**：`npx quartz build` 产出纯静态文件，官方 Actions 工作流一键部署；
4. **维护活跃**：v5.0.0（2026 年仍在持续发布），社区插件生态（`@quartz-community/*`），组件化布局，可通过 `quartz.config.yaml` 配置，也可写自定义组件；
5. **中文支持好**：`locale: zh-CN`，日期/搜索/内容元信息均本地化。

**本项目的关键定制**（v5 默认偏"知识库工具感"，我们做了大量减法）：

- 去掉：左侧文件树（Explorer）、面包屑、阅读模式、标签页、元信息表格、站名侧栏；
- 保留并调整：本页目录（改为左缘抽屉）、搜索、暗色模式、日期（低调小字）、sitemap；
- 新增（`quartz/components/maze/` 自定义组件）：右上角图标簇、带摘要的反向链接、探索进度、全站统计、最近更新浮层、目录抽屉。

## 4. 核心数据流

```
[写作]  Obsidian 打开 content/（即 vault）
   │  写下 [[双链]]、frontmatter（title/description/permalink）
   ▼
[提交]  Obsidian Git 插件自动 commit + push（或手动 git）
   │
   ▼
[构建]  GitHub Actions（deploy.yml）
   │  1. npm ci
   │  2. npx quartz plugin install --from-config
   │  3. npx quartz build
   │     ├─ 读取 quartz.config.yaml（插件与布局槽位）
   │     ├─ config-loader.ts 组装布局（注入迷宫组件）
   │     ├─ 解析 frontmatter / 双链 → 生成反向链接、图谱数据、contentIndex
   │     └─ 输出静态 HTML+CSS+JS 到 public/
   ▼
[发布]  actions/deploy-pages → GitHub Pages
   │
   ▼
[访问]  访客 → knink-owo.github.io/Maze-garden
   ├─ 悬停双链 → Popover 全文预览（可滚动、可定位小节）
   ├─ 右上角图标簇 → 搜索/音乐/随机漫步/最近/图谱
   ├─ 左缘目录抽屉 → 目录 + 字数
   └─ 文章底部 → 日期 + 已探索 N + 反向链接
```

**关键约定：**

- **日期**：自定义转换器 `mazeDates.ts` 按 `frontmatter → git 历史 → 文件系统` 优先级推断；创建时间取 **git 首次提交**、修改时间取 **git 最近提交**；自定义组件 `ArticleDates` 在文章底部显示"创建于 + 更新于"两个日期（空文章也显示）。补录旧文时用 frontmatter `created:`（或 `date:`）/ `modified:` 覆盖。
- **链接解析**：`markdownLinkResolution: shortest`（Obsidian 默认），中文文件名/文件夹直接使用（URL 会百分号编码，站内全走双链，无感知）。
- **分享 URL**：frontmatter `permalink: pretty-url` 可覆盖为干净 URL，且文件改名后不变。
- **发布控制**：全公开；`draft: true` 不发布（remove-draft 插件）。

## 5. 布局槽位（v5）

每个插件通过 `layout.position`（`header / left / right / beforeBody / afterBody / footer`）+ `layout.priority` 挂载；页面帧（frame）决定整体骨架：

- 本项目使用 **default 帧**，但通过 `custom.scss` 隐藏两侧栏并把网格改为**单列**（内容区全宽，正文再限宽居中）；
- 左缘：目录滑块（TocDrawer，fixed 定位覆盖层）；
- 头部（右上角）：搜索、暗色模式、图谱（隐藏局部图盒子）、迷宫图标簇；
- 内容底部（afterBody）：日期（创建/更新时间 ArticleDates）→ 反向链接 → 已探索 N；主页额外有全站统计；每页带隐藏的"最近更新"浮层与目录抽屉；
- 页脚：GitHub 链接。

## 6. 已知限制与后续

- **GitHub Pages 子路径 + 相对链接**：相对链接依赖"当前 URL 目录"，进入 URL 异常时（无尾斜杠/回退/404 态）会丢子路径。方案：**页面加载时把所有内部 `./`、`../` 链接转成带子路径的绝对链接**（`MazeIcons.tsx` 内 `normalizeInternalLinks`，加载与 SPA nav 后各执行一次），之后链接不再受当前 URL 形态影响。**改动该脚本或升级 Quartz 时请保留**。注意：曾尝试 `<base>` 标签方案，会破坏 `../` 双链解析，已弃用。
- 本地插件源依赖符号链接，在 Windows（无开发者模式）下不可用 → 因此自定义组件放在核心 `quartz/components/maze/`，通过修改 `config-loader.ts` 注入；升级 Quartz 时需迁移（把组件迁入新核心或转成社区插件）。
- GitHub Pages 生成 `xxx.html`（无尾斜杠），迁移旧站注意 404 重定向。
- 音乐文件需手动放入 `quartz/static/music/`，构建后按钮才出现。
