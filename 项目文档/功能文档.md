# 迷宫花园 · 功能文档

> 版本：2026-09（v1.0）—— 当前已实现功能清单 + 后续发展方向。

---

## 1. 已实现功能（v1.0）

### 1.1 内容与写作

| 功能 | 说明 | 实现方式 |
| --- | --- | --- |
| Obsidian Markdown | `content/` 即 vault，Obsidian 直接打开写作 | Quartz 5 + Obsidian Flavored Markdown |
| `[[双链]]` 全语法 | `[[标题]]`、`[[标题|别名]]`、`[[标题#小节]]`、`![[嵌入]]`、`![[图片.png]]` | obsidian-flavored-markdown 插件 |
| 未解析链接 | 灰色显示（房间还没盖好） | Quartz 默认 |
| Frontmatter | `title` / `description` / `aliases` / `permalink` / `draft` / `date` | note-properties（只解析不显示） |
| 别名重定向 | `aliases` 直达文章 | alias-redirects 插件 |
| 日期自动推断 | 创建/修改日期取自 git 历史（零维护） | created-modified-date（`defaultDateType: modified`） |
| 草稿 | `draft: true` 不发布 | remove-draft 插件 |

### 1.2 迷宫式导航

| 功能 | 说明 |
| --- | --- |
| 入口文章 | `content/index.md` 即主页唯一文章，无导航栏/分类/标签 |
| 反向链接（带摘要） | 文章底部列出所有链接到本文的文章，标题 + frontmatter `description` 摘要（自定义组件 `Backlinks.tsx`，社区版只显示标题） |
| 悬停预览（可滚动全文） | 鼠标悬浮双链弹出目标文章内容，**可滚动读完**；`[[文章#标题]]` 自动定位到该小节（Quartz Popover 原生能力） |
| 随机漫步 🎲 | 右上角按钮，随机跳到任意一篇文章（排除当前页，SPA 无刷新跳转） |
| 关系图谱 🕸 | 默认隐藏；右上角按钮召唤**全站图谱**（全屏浮层），局部图盒子已隐藏 |
| 最近更新 🕘 | 右上角按钮召唤浮层：按修改时间倒序 10 条（标题+摘要+日期）+ 全站统计 |
| 搜索 🔍 | 右上角图标，全文搜索（含预览），中文可用 |

### 1.3 氛围与体验

| 功能 | 说明 |
| --- | --- |
| 探索进度 | 文章日期下方显示"已探索 N"（localStorage 记录去重访问过的文章，访客本地数据） |
| 全站统计 | 主页入口文章底部："共 N 篇文章 · 约 M 字 · L 条链接" |
| 背景音乐 ♪ | 右上角音乐按钮：放入 `quartz/static/music/` 的音频，点击播放/暂停、循环、**跨页面不中断**（SPA 不重建 audio） |
| 主题切换 ☀/🌙 | 默认跟随系统，手动切换后记忆（darkmode 插件） |
| 本页目录 | 右侧栏，默认折叠，点击展开（table-of-contents `collapseByDefault: true`） |
| RSS 📡 | 右上角图标 → `index.xml` |
| 分享链接 | frontmatter `permalink: pretty-url` → 干净 URL 且改名不变 |

### 1.4 视觉

- **暖纸色 + 深墨色**：浅色 `#FAF6EF` 纸底 / `#2B2620` 墨字，链接暖棕 `#8C6A3F`；暗色模式深底米字；
- 字体：标题 思源宋体（Noto Serif SC）、正文 思源黑体（Noto Sans SC）、代码 JetBrains Mono（Google Fonts）；
- 极简排版：正文限宽 46rem，图标低透明度（0.5 → 悬停 1），全部交互克制。

## 2. 配置速查（`quartz.config.yaml`）

```yaml
configuration:
  pageTitle: 迷宫花园
  pageTitleSuffix: " · 墨水-knink"
  locale: zh-CN
  baseUrl: knink-owo.github.io/Maze-garden
  theme: { ... 暖纸色配色 + 字体 ... }
```

- 改站点名/作者：`pageTitle` / `pageTitleSuffix`
- 改颜色：`theme.colors.lightMode` / `darkMode`
- 改插件：`plugins:` 列表（`enabled` / `layout.position` / `layout.priority`）
- 加字体：`theme.typography`
